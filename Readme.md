## Завдання

Усі функції розміщені у файлі **`src/script.js`**. Напишіть реалізацію для кожної з них замість коментаря `// TODO: Implement function`.

1. **`getType(value)`** — повертає тип значення за допомогою оператора `typeof`.
2. **`isNullOrUndefined(value)`** — перевіряє, чи є значення строго `null` або `undefined`.
3. **`convertToNumber(value)`** — конвертує значення у число (повертає `NaN`, якщо перетворення неможливе).
4. **`isNaNValue(value)`** — строго перевіряє, чи є значення саме `NaN` (`Number.isNaN`).
5. **`safeAdd(a, b)`** — конвертує обидва аргументи в числа та повертає їх суму.
6. **`capitalizeWord(str)`** — робить першу літеру заданого рядка великою.
7. **`containsIgnoreCase(str, target)`** — перевіряє наявність підрядка без урахування регістру.
8. **`roundToDecimal(num, decimals)`** — округлює число до вказаної кількості знаків після коми.
9. **`isLeapYear(year)`** — визначає, чи є рік високосним.
10. **`isValidPassword(password)`** — перевіряє, чи пароль містить від 8 символів та хоча б одну цифру.

### Помилка запуску скриптів у Windows (PowerShell)
Якщо при виконанні команди `npm test` у терміналі виникає помилка:
> *"... cannot be loaded because running scripts is disabled on this system."*

**Вирішення (два варіанти на вибір):**

1. **Тимчасово дозволити запуск скриптів:**
   Виконайте у терміналі PowerShell команду:
  
 ```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
```

*(Цей дозвіл застосовується лише для поточної сесії термінала і зникає після його закриття).*

2. **Змінити тип термінала у VS Code:**
У правому куті панелі термінала натисніть на стрілочку поруч із знаком `+` (або виберіть профіль за замовчуванням) та переключіть термінал з **PowerShell** на **Git Bash** або **Command Prompt (CMD)**. У них немає обмежень щодо політики виконання скриптів.
